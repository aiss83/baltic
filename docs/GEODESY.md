# Геодезические основы

Документ описывает модель, которая используется в `libbaltic`, и границы её
применимости. Он не заменяет нормативные документы по Балтийской системе
высот и не является инструкцией по уравниванию нивелирных сетей.

## 1. Высоты и поверхности

- **Эллипсоидальная (геодезическая) высота `h`** — расстояние от точки до
  референц-эллипсоида по нормали. В библиотеке используется WGS 84.
  Типичный источник — GNSS.
- **Ортометрическая высота `H`** — расстояние от точки до геоида по
  отвесной линии.
- **Геоид** — уровенная поверхность потенциала силы тяжести, совпадающая с
  невозмущённой поверхностью океана (с точностью до течений и т.п.).
- **Высота геоида `N`** — превышение геоида над эллипсоидом:
  `h = H + N`.
- **Нормальная высота `H^γ`** — высота в системе нормального потенциала;
  связана с квазигеоидом и аномалией высоты `ζ`: `h = H^γ + ζ`.
- **Балтийская система высот 1977 г. (БСВ-77)** — система нормальных
  высот с нулём Кронштадтского футштока.

Для ортометрических высот `N` — это геоид; для нормальных высот
используется квазигеоид (`ζ`). Разность `N − ζ` в равнинных районах
обычно составляет дециметры, в горах — метры, и может быть учтена
поправочной сеткой `C`.

## 2. Модель библиотеки

```
H = h − N_EGM2008(lat, lon) + C(lat, lon) + Δ
```

- `N_EGM2008` — высота геоида EGM2008, интерполированная по сетке
  2.5′ (или 1′). Для сетки EGM2008 используется операция PROJ
  `vgridshift` с `+multiplier=1`:
  - прямой ход `H → h`: `h = H + N` (это соответствует EPSG:3855 → EPSG:4979);
  - обратный ход `h → H`: `H = h − N`.
- `C` — необязательная аддитивная поправка, задаваемая пользовательской
  вертикальной сеткой. Формально она добавляется к балтийской высоте:
  `H = (h − N) + C + Δ`. Это позволяет подключить региональную модель
  квазигеоида, разность «национальная модель − EGM2008» или поправку за
  различие геоид/квазигеоид. Если региональная модель задаёт аномалию
  высоты `ζ_reg`, то для перехода к нормальным высотам нужно
  `C = N_EGM2008 − ζ_reg` (знак проверяйте по описанию модели).
- `Δ` — постоянная поправка датума. Она компенсирует смещение нуля
  БСВ-77 относительно геоида EGM2008 и систематические различия модели
  в районе работ.

### Почему нужна поправка `Δ`

EGM2008 — глобальная гравиметрическая модель; её геоид и ортометрические
высоты не привязаны к нулю Кронштадтского футштока. БСВ-77 — нормальные
высоты, полученные из нивелирования и привязанные к конкретному нулю.
Поэтому даже при идеальной модели `N` разность `H_БСВ − (h − N)` содержит
постоянную составляющую (плюс региональные вариации). Эта составляющая
оценивается по пунктам, где известны и GNSS-высота `h`, и высота БСВ-77 `H`.

Без калибровки (`Δ = 0`) результат является высотой относительно геоида
EGM2008, а не высотой БСВ-77.

## 3. EGM2008

EGM2008 — модель гравитационного поля Земли до степени/порядка 2190,
построенная NGA. Для практических вычислений высот геоида используется
сетка значений `N` на географической сетке:

- 2.5′ — 8641 × 4321 узлов, глобальное покрытие;
- 1′ — 21601 × 10801 узлов (более высокое разрешение, больший объём).

Файлы `us_nga_egm08_25.tif` и аналогичные — это GeoTIFF-сетки PROJ, где
значения узлов заданы в метрах. Горизонтальная привязка — WGS 84,
вертикальная — высоты геоида EGM2008 (ортометрические).

Модель EGM2008 имеет собственную точность (по оценкам NGA — порядка
дециметров в глобальном масштабе, лучше в районах с плотной гравиметрией).
Она не заменяет локальную модель, созданную по наземным данным.

## 4. Интерполяция и покрытие

PROJ выполняет билинейную интерполяцию по четырём узлам сетки. Для
линейного поля результат точен; для реального геоида погрешность
интерполяции на сетке 2.5′ — обычно сантиметры. На границах сетки
используются крайние узлы; за пределами покрытия PROJ возвращает ошибку,
которая транслируется в `BALTIC_ERR_OUT_OF_GRID`.

Для EGM2008 покрытие глобальное (широта −90…+90, долгота −180…+180),
поэтому ошибка вне сетки возможна только для региональных поправочных
сеток.

## 5. Калибровка `Δ`

Пусть есть `n` контрольных пунктов с известными `h_i` (GNSS) и `H_i`
(БСВ-77). Для каждого вычисляется модельная высота без поправки:

```
H_model,i = h_i − N_i + C_i
r_i = H_i − H_model,i
Δ = (1/n) Σ r_i
RMS = sqrt((1/n) Σ (r_i − Δ)²)
```

`Δ` — это оценка постоянной поправки (метод наименьших квадратов для
модели «константа»). `RMS` показывает, насколько хорошо одна константа
описывает район. Большой RMS (например, больше 5–10 см) означает, что
следует использовать региональную поправку `C` или проверить качество
исходных данных.

Требования к калибровке:

- пункты должны быть равномерно распределены по району работ;
- высоты БСВ-77 — из нивелирования соответствующего класса;
- GNSS-высоты — с известной и приемлемой точностью (обычно не хуже
  нескольких сантиметров);
- число пунктов — не менее 3–5; для больших территорий — больше;
- калибровка действительна только для района и эпохи исходных данных.

## 6. Порядок вычислений в библиотеке

Прямое преобразование `h → H`:

1. `z = h`;
2. `z = vgridshift_EGM2008⁻¹(z)` → `z = h − N`;
3. если задана поправка: `z = vgridshift_C(z)` → `z = h − N + C`;
4. `H = z + Δ`.

Обратное `H → h`:

1. `z = H − Δ`;
2. если задана поправка: `z = vgridshift_C⁻¹(z)` → `z = H − Δ − C`;
3. `z = vgridshift_EGM2008(z)` → `z = H − Δ − C + N = h`.

Обе операции используют один и тот же контекст и сериализуются мьютексом,
поэтому контекст можно использовать из нескольких потоков.

## 7. Системы отсчёта и tide system

Сетки NGA EGM2008, как правило, относятся к **mean-tide** системе
(это указано в описании файлов NGA); метаданные конкретного зеркала или
файла могут отличаться. Если исходные GNSS/нивелирные данные приведены в
другой системе приливов (zero-tide и т.п.), возможно систематическое
смещение порядка сантиметров, а в высоких широтах — до дециметров.
Для строгих работ проверяйте описание сетки и нормативные требования и,
при необходимости, вводите поправку за систему приливов.

Горизонтальные координаты должны быть в WGS 84. ПЗ-90.11 отличается от
WGS 84 на уровне сантиметров; для высот это обычно пренебрежимо, но
если требуется строгое соответствие, преобразуйте горизонтальные
координаты заранее.

## 8. Бюджет ошибок (ориентировочно)

| Источник | Порядок |
|---|---|
| Дискретизация/интерполяция EGM2008 2.5′ | см |
| Погрешность модели EGM2008 | дм (зависит от района) |
| Различие геоид/квазигеоид, не учтённое в `C` | дм … м (рельеф) |
| Привязка к БСВ-77 (`Δ`) | зависит от калибровки |
| GNSS-высота | см … дм |
| Исходное нивелирование | мм … см |

Эти оценки не являются гарантией точности; для производственных работ
необходима независимая проверка на контрольных пунктах.
