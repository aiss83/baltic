# Участие в проекте

Спасибо за интерес к `baltic`.

## Перед началом

- Для ошибок и предложений используйте GitHub Issues.
- Для существенных изменений сначала опишите задачу в issue.
- Не коммитьте `data/egm2008/*.tif`, build-каталоги и сгенерированную
  документацию: они исключены через `.gitignore`.

## Сборка и тесты

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure
```

Без 80-МБ сетки EGM2008 тесты `egm2008` и `cli` будут пропущены, но
`api` и `embedded` выполнятся. Для полного прогона:

```sh
./scripts/fetch-egm2008.sh
```

## Стиль кода

- Полная библиотека — C11, встроенная — C99.
- Публичные заголовки не должны включать `proj.h`.
- Никаких глобальных изменяемых состояний в `embedded`.
- Ошибки — через `baltic_status`/`baltic_embedded_status`, без silent
  fallback.
- Комментарии и документация — по-русски или по-английски; API-комментарии
  в заголовках — на английском.
- Форматирование — 4 пробела, без табов; строки желательно ≤ 88 символов.

## Сетки

Сгенерированные `embedded/grids/*.c` и `*.h` не редактируются вручную.
После изменения генератора перегенерируйте их:

```sh
./build/egm2008_to_c --grid data/egm2008/us_nga_egm08_25.tif \
    --name egm2008_moscow_2deg --out-dir embedded/grids \
    --lat-min 54 --lat-max 56 --lon-min 36 --lon-max 38
```

При добавлении новой сетки:

- приложите команду генерации в `embedded/grids/README.md`;
- проверьте, что `ctest` проходит;
- не добавляйте исходный GeoTIFF в git.

## Документация

- Markdown — в `docs/`; главная страница — `docs/INDEX.md`.
- Doxygen-комментарии — в публичных заголовках.
- После изменений API обновите `docs/API.md` и `README.md`.

```sh
doxygen Doxyfile
```

## Pull request

- Один PR — одна тема.
- Убедитесь, что CI зелёный.
- Опишите изменение, влияние на API/ABI и проверку.
- Для новых возможностей добавьте тесты.
